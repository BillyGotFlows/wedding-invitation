# دعوة زفاف فاخرة (French Baroque Luxury) | بكري واتار & رحاب

موقع دعوة زفاف رقمية وتفاعلية بتصميم ملكي مستوحى من الطراز الباروكي الفرنسي الكلاسيكي (French Baroque) باللونين الأزرق الملكي والأزرق الداكن مع لمسات الذهب الأثري (Antique Gold & Royal Blue).

---

## ✨ المميزات الرئيسية
- 👑 **واجهة دخول ملكية بالختم الشمعي (Wax Seal Entrance)**: بطاقة افتتاحية مع مونوغرام العروسين **(ب & ر)** وزر فتح الدعوة.
- ⏳ **عد تنازلي مباشر (Live Countdown)**: حساب دقيق للأيام والساعات والدقائق حتى موعد الزفاف في 28 أيلول 2026 الساعة 7:30 مساءً.
- 📍 **قاعة الحفل والموقع**:
  - صالة ايفانكا - نادي الضباط - الفرقان (حلب).
  - زر مباشر للانتقال إلى الموقع على خرائط Google.
  - زر إضافة الموعد إلى تقويم Google وتحميل ملف تقويم Apple / Outlook (`.ics`).
- ✍️ **تأكيد الحضور (RSVP) ونظام الواتساب المباشر**:
  - نموذج تسجيل الحضور مع تحديد عدد المرافقين وكتابة التهنئة.
  - زر بنقرة واحدة لإرسال رسالة التهنئة والتأكيد منسقة مسبقاً عبر **واتساب (WhatsApp)**.
  - حفظ الردود تلقائياً في المتصفح مع نافذة خاصة للعروسين للاطلاع على إجمالي عدد الحضور.
- 💌 **دفتر التهاني والتباريك (Guestbook)**: عرض كلمات التهنئة والمحبة في بطاقات مذهبة.
- 🎵 **عزف كلاسيكي هادئ (Ambient Classical Music)**: متوافق مع كافة المتصفحات وبزر عائم للتشغيل والكتم.
- 📱 **متجاوب بالكامل (100% Mobile Responsive)**: مخصص ومحسن لفتح الرابط مباشرة من تطبيقات الدردشة (واتساب، تيليغرام، إنستغرام).

---

## 🚀 طريقة التشغيل والمعاينة السريعة
1. افتح الملف `index.html` في أي متصفح (Chrome, Safari, Edge, Firefox) بالنقر المزدوج عليه.
2. يمكنك استخدام إضافة **Live Server** في VS Code أو تشغيل خادم محلي:
   ```bash
   npx serve .
   ```

---

## 📲 تخصيص رقم الواتساب الخاص بالعروسين
في الوضع الافتراضي، يقوم زر الواتساب بفتح تطبيق واتساب مع رسالة جاهزة ليختار الضيف إلى من يرسلها.
إذا رغبت في تحديد رقم هاتف معين لاستلام كافة الردود مباشرة:
1. افتح الملف `assets/js/rsvp.js`
2. ابحث عن السطر:
   ```javascript
   whatsappShareBtn.href = `https://api.whatsapp.com/send?text=${encodeURIComponent(whatsappText)}`;
   ```
3. أضف رقمك مع الرمز الدولي (مثال: `963912345678`):
   ```javascript
   whatsappShareBtn.href = `https://api.whatsapp.com/send?phone=963912345678&text=${encodeURIComponent(whatsappText)}`;
   ```
